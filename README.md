# 清醒 · 本机自我管理

中文、温和、自愿使用的自我管理应用。个人记录默认只保存在当前浏览器，不需要账户，不进行分析追踪或自动同步。

## 下载后直接使用

下载本分支的源码 ZIP 并解压，打开 `distribution/清醒-本地学习版.html`。页面内已包含脚本、样式与插画，不需要安装依赖或联网。

请用同一浏览器打开固定位置的文件。换电脑、移动文件或清理浏览器数据前，在“偏好设置 → 导出我的记录”保存 JSON 备份，之后可确认导入恢复。浏览器存储和备份都是明文，请妥善保管。

若浏览器不允许打开本地 HTML，安装 Python 3 后在解压目录运行：

```sh
python3 -m http.server 4175 --bind 127.0.0.1 --directory distribution
```

打开 `http://127.0.0.1:4175/`，点击中文 HTML 文件。云环境禁止 `file://`，因此直接双击未在本环境验证；同一文件经本机 HTTP 加载后的断网运行和浏览器重启持久化已验证。关闭本机服务用 Ctrl+C。

## 功能目录

- **我的概览**：每日状态自评、可选日记、习惯完成情况；同日重复打卡更新原记录。
- **我的计划**：自己的目标文字、1–3650 天周期、自定义习惯。连续天数表示自评记录，不代表禁欲天数。
- **成长记录**：日历、统计与记录查看、JSON 导出。
- **静心工具**：一分钟呼吸、5 / 15 / 25 分钟专注计时，支持暂停、继续和重置；关闭弹窗结束计时。
- **资料目录**：手动保存、分类、筛选和删除 HTTP(S) 来源链接。**来源学习卡片**包含 3 条百度贴吧戒色吧公开目录标题线索与 2 张医学核查卡；原帖正文访问返回 403，明确标注未读，不伪造思想摘要。按主题阅读，可保存个人思考、自愿选择或取消小行动；没有实时抓取、爬虫或任意 URL 服务端代理。保存链接不会访问网站，主动点击才打开第三方来源。
- **偏好设置**：中性鼓励短句默认关闭，可随时开启；页面内提醒、完整备份导入导出和清除确认。
- **学习与积分**：可自愿使用已有短课、自定行为分值和阶段记录。积分不衡量个人价值，也不是健康评价。

普通性欲不是失败；工具不提供诊断，不声称禁欲能治病，不监视浏览历史、不锁机、不修改 DNS。详见 [隐私说明](PRIVACY.md)。

## 开发运行

使用 Node.js 20.19+ 或 22.12+；本次在 Node.js 24.19.0 验证。

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。开发与预览服务仅监听本机回环地址。

```sh
npm test
npm run build
npm run build:offline
```

`build` 生成 `dist/`；`build:offline` 生成离线 HTML、说明和 `.local/qingxing-offline.zip`，并更新 `distribution/` 分发目录。离线打包需要系统 `zip` 命令。

启动开发服务后，另一终端运行：

```sh
npm run test:e2e
npm run test:resources
npm run test:reading
```

浏览器测试默认使用 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 指定路径，`BASE_URL` 指定本机服务。测试使用隔离浏览器上下文和人工测试夹具，不接触真实用户记录；输出在 Git 忽略的 `test-results/`。离线验证方法和限制见 [验证报告](VALIDATION.md)。

来源及访问范围见 [SOURCES.md](SOURCES.md)。阅读思考和行动选择随 JSON 备份导入导出，清除全部记录时一并清除。

## 源码目录

- `src/`：React 界面、本机数据与备份逻辑、单元测试。
- `public/`：项目自带图标与插画，无外部字体或图片依赖。
- `scripts/`：离线打包、浏览器验证脚本。
- `distribution/`：可下载运行的自包含页面和中文说明。

本分支提供代码与离线分发文件，不自动部署网站。
